## Approach

Security is not a feature you add at the end. I learned that by finding the gaps others left open - undocumented admin gateways, unthrottled login handlers, hardcoded credentials in client-side code. Every vulnerability I document in a lab is a pattern I know to prevent when I build.

The goal is not just to pass assessments. It is to think like an attacker so I can architect like a defender.
